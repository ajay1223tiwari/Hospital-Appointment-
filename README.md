# Medicare - Doctor Appointment Booking Platform

A full-stack doctor appointment booking platform built using the MERN stack. The platform allows users to book appointments with doctors, make secure online payments, and manage healthcare services efficiently.

---
## 🚀 Live Demo
[https://your-live-link.vercel.app](https://hospital-appointment-xi.vercel.app/)

## 🌟 Features

### 👤 User Features
- User Registration & Login
- JWT Authentication
- Book Doctor Appointments
- Online Payment Integration using Stripe
- View Appointment History
- Responsive UI

### 👨‍⚕️ Doctor Features
- Doctor Profile Management
- Appointment Scheduling
- Availability Management

### 🛠️ Admin Features
- Admin Dashboard
- Manage Doctors & Users
- Monitor Appointments
- Secure Role-Based Access Control
